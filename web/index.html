      Use local models

      Choose an instruction-tuned .gguf file from your device. One model can play both roles, or you can give the reviewer a different model.

      In current desktop Chrome or Edge, start with a small model: choose a Q4_K_M file for Qwen2.5 0.5B Instruct . Files never upload; choose them again after a reload.

      How a relay works

      Draft & review
      The driver drafts a response, the reviewer critiques it, and the driver writes a final answer using that feedback.
      Compare answers
      Both models answer the same prompt independently, so you can compare their approaches.
      Demo vs. local AI
      The demo uses scripted examples. With a GGUF model selected, inference runs on your CPU in a supported browser. No model downloads automatically, and prompts are never sent to a server.

      The original Frenemy desktop tools are separate. This web edition does not log into Claude, Codex, Gemini, or Kimi or run commands on your machine.
